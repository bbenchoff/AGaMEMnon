The die splits in two
Hard MCU / SoC fills the top-left — RISC-V core, 256KB flash, 128KB SRAM, hard peripherals. It is real silicon but not FPGA, so it holds no fabric tiles; it meets the fabric only along the Y5 boundary spine, where the AHB port (M, X10Y5) hands signals across. The FPGA fabric wraps it in an L: a full bottom band plus the tall right column.

Correction to the earlier "whole chip": that showed only the 159 tiles with placeable bels. The routing graph actually spans 190 tiles — the extra 31 are routing-only switch tiles (the Y5 boundary spine and the X21 spacer column, which carries routing but no ordinary slices). And the largest blank region was never missing data: it's the hard MCU, which by definition has no fabric tiles.
